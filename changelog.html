Changelog

Every Klarity Disk release, newest first.

1.3 — in review

  • Move to Trash works everywhere. Klarity asks for access to your disk once, explains why, and remembers it per volume.
  • Scan Macintosh HD with one click. The scanner no longer double-counts the APFS data volume.
  • Honest admin message. Items macOS protects show “Finder needs an admin password” with Reveal in Finder.
  • Refresh Interval now takes effect and is remembered; menu bar preferences are remembered.
  • Scanning a folder Klarity can’t read yet (like Downloads before any grant) now asks for access instead of showing an empty result.
  • The build number now shows after the version, e.g. 1.3 (1300).

1.2 — 21 April 2026

  • Age Heatmap. Colour files by age on a teal-to-coral scale with a continuous colour bar and a live hover marker.
  • Animated drill-down transitions, sidebar scan pulse, scan-result fade-in, breadcrumb overflow fades.
  • Fixed the all-red heatmap for directories and garbled arrow text in the empty state.
  • Accessibility: 89+ WCAG 2.1 AA contrast fixes and full VoiceOver support.

1.1 — 1 March 2026

  • Move to Trash from the treemap, icicle chart, and info panel, using Finder’s recoverable Trash.
  • Slide-to-confirm safety for folders over 1 GB.
  • Scan completion banner with item count, size, and duration.
  • Remembers your last scan path; grant access to a folder once.
  • Three-way appearance mode and renamed theme packs (Arctic, Ember, Verdant, Blush).

1.0 — 13 February 2026

  • Initial release: treemap and icicle disk visualisation, large file finder, RAM and process monitor, menu bar readout, six themes.
