How to See Folder Sizes on a Mac: 4 Ways That Work

The Finder shows two dashes where a folder’s size should be. Here is how to turn the numbers on, how to see a whole folder at once, and why two tools can give two answers.

Why the Finder shows two dashes

Open any Finder window in list view and look at the Size column. Files have a size. Folders have two dashes.

The Finder is not hiding anything. A folder’s size is not stored anywhere; it has to be added up from everything inside, and for a big folder that takes time. So the Finder waits until you ask. There are three ways to ask with what is already on your Mac, and one that draws a whole folder as a picture.

1. In a Finder window: Calculate all sizes

  1. Open the folder and switch to list view (View → as List).
  2. Choose View → Show View Options, or press Cmd + J.
  3. Tick Calculate all sizes.
  4. Click the Size column heading to put the largest at the top.

The dashes turn into numbers, one folder at a time. Two things to know. The setting belongs to the folder you are in: open another folder and you get dashes again, unless you click Use as Defaults at the bottom of the options window. And each level is added up separately. To learn what is inside the biggest folder, you open it and wait again.

Every folder is a rectangle, and its size on screen is the space it takes on disk. 3. One folder: Get Info

Select a folder and choose File → Get Info, or press Cmd + I. The window adds the folder up and shows its size, with the space it takes on disk in brackets beside it.

Two variations save time:

  • One window that follows you. Press Option + Cmd + I to open the inspector. It looks like Get Info, but it changes as you click from folder to folder, so you are not left with ten open windows.
  • Several folders added together. Select them, hold the Control key, and choose File → Get Summary Info. You get one total for the selection.

4. Storage settings: the File Browser

Apple has a folder-size view of its own, and it is easy to miss.

  1. Open System Settings → General → Storage.
  2. Find Documents in the list and click the Info button beside it.
  3. Click File Browser.

You get your folders in columns with the storage each one uses, and you can sort by size. Apple notes one limit: folders that already have their own category in Storage settings, other than Documents, are dimmed here. So it is a good view of your documents and a partial view of everything else.

Why two tools give two numbers

Sooner or later you will see one folder with two different sizes. Usually nothing is wrong. The tools are counting different things.

  • Size and size on disk. Get Info shows both. The first is how much data the files hold; the second is the space they take up on the drive. Some files, such as virtual machine disks, report a size far larger than the space they actually take. Klarity shows the on-disk figure, the same one the Finder puts in brackets, because that is usually the space you get back.
  • Protected app folders. macOS can stop one app reading another app’s data, so Klarity can show such a folder as smaller than the Finder does.
  • Files kept in iCloud. With Optimize Mac Storage on, a file can be listed on your Mac while its contents are only in iCloud. It has a size, and takes almost no space on disk.
  • Available is not the same as free. Apple says disk space “might be both available and used at the same time”. That is purgeable space: space in use now that macOS will clear when it is needed.

Which one to use

  • One folder, right now: Get Info.
  • A handful of folders in one place: Calculate all sizes.
  • Your documents, by size: the File Browser in Storage settings.
  • “Where did my disk go?”: a map of the whole disk.

Questions people ask

How do I show folder sizes in Finder on a Mac?

Open the folder in list view, choose View, then Show View Options (or press Cmd + J), and tick Calculate all sizes. The Size column then shows a number for each folder. Click Use as Defaults to apply it to other folders that have no view settings of their own.

Why does Finder show two dashes where a folder’s size should be?

A folder’s size is not stored; the Finder has to add up everything inside it, which takes time. So it shows dashes until you turn on Calculate all sizes, or open Get Info for that folder.

What is the shortcut for a folder’s size on a Mac?

Select the folder and press Cmd + I for Get Info. Press Option + Cmd + I for the inspector, a single window that updates as you select other folders.

Why is size on disk different from size?

Size is how much data the files hold. Size on disk is the space they take up on the drive. They differ for files that report more than they take up, such as virtual machine disks, and for files whose contents are kept in iCloud.
